# Online Quiz System

A robust and responsive **Java-based Online Quiz System** designed to facilitate seamless examination management, live test-taking, score tracking, and automated question evaluation.

## 🚀 Features
* **User Authentication:** Secure login system for both students and teachers.
* **Teacher Dashboard:** Easily add, update, and manage multiple-choice questions (MCQs).
* **Interactive Quiz Interface:** A clean UI for students to attempt quizzes within specified constraints.
* **Instant Evaluation:** Automated score calculation right after quiz submission.
* **Data Persistence:** Keeps track of records using robust backend logic.

## 🛠️ Tech Stack
* **Language:** Java
* **Concepts Used:** Object-Oriented Programming (OOPs), File Handling / Data structures

## 📁 Project Structure
The repository contains the main application components:
* `teacher.java` & `teacher.class` - Teacher management module
* `PlayQuiz.java` & `PlayQuiz.class` - Student examination interface
* `Question.class` & `quiz.dat` - Question structure and data storage
